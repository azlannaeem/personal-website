## Overview

A secure, modular password and security manager built in Java following clean
architecture principles, with MySQL-backed credential storage.

## Highlights

- Implemented bcrypt/Argon2 password hashing and AES-256 encryption for
  credential storage, plus TOTP-based two-factor authentication.
- Integrated external APIs for malware and data breach detection, alongside
  password generation and entropy-based security assessment.
- Designed a normalized MySQL schema and REST API layer to support secure,
  streamlined authentication workflows.
